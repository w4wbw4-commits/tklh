# إزالة زري التخطيط ولوحة التحكم من شريط التنقل العلوي

## الهدف
إزالة الخيارين اللذين يظهران حاليًا في الزاوية العلوية من شريط التنقل:
1.  **"خطط واحجز الآن"** — الزر الرئيسي المؤدي إلى `/planner`.
2.  **"متابعة الخطة"** — الزر المؤدي إلى `/dashboard`.

## نطاق التعديل
تعديل واحد فقط في واجهة العميل:
-   `src/components/tekillah/Navbar.tsx`

لا تمتد التعديلات إلى:
-   قائمة الجوال/الهامبرغر (`SiteMenuSheet.tsx`) — يبقى الرابط إلى `/dashboard` متاحًا هناك.
-   الصفحات الداخلية (`/planner`, `/dashboard`, `/admin`, بوابة الشريك، لوحة الإدارة).
-   الـ backend / RLS / API / قاعدة البيانات.

## الخطوات
1. **حذف زر "خطط واحجز الآن"**
   - إزالة كتلة `<Button asChild ...>` التي تحتوي على `<Link to="/planner">` والنص `t("common.planAndBook")`.

2. **حذف زر "متابعة الخطة"**
   - إزالة كتلة `<Button variant="ghost" ...>` التي تحتوي على `<Link to="/dashboard">` والنص `t("nav.myDashboard")`.

3. **تنظيف الاستيرادات**
   - حذف `CalendarCheck` و `LayoutDashboard` من استيراد `lucide-react` لأنهما لن يُستخدما بعد التعديل.

4. **إبقاء ما يلي كما هو**
   - زر الإدارة (`nav.admin`) المخصص للمستخدمين ذوي الصلاحية.
   - زر قائمة الهامبرغر (`SiteMenuSheet`).
   - منطق تبديل ألوان الشريط العلوي (`navbarTheme`).
   - الترحيب التشخيصي للمدير الرئيسي.

## التحقق بعد التنفيذ
-   `bunx tsgo --noEmit`
-   `bun run build`
-   فحص بصري على 375px / 768px / 1440px بالعربية والإنجليزية للتأكد من عدم ظهور الزرين ومن عدم تداخل العناصر المتبقية.

## المخاطر
-   قد يقلل حذف الـ CTA الرئيسي من وضوح الدعوة للتخطيط، لكن المستخدم طلب الإزالة صراحةً.
-   رابط `/dashboard` يبقى متاحًا عبر قائمة الهامبرغر، و `/planner` يبقى متاحًا كمسار مباشر.
