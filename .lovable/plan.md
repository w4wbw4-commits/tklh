# تحسين الهوية البصرية للرئيسية فقط

## النتيجة
تطوير الصفحة الرئيسية العامة `/` بصرياً دون تغيير محتواها أو صورها أو سلوكها، مع إبقاء أخضر تكله `#163726` لون الهوية الأساسي.

## التنفيذ
- إضافة نطاق تصميم خاص بالرئيسية يمنع انتقال الألوان أو الخطوط أو القياسات إلى صفحات العميل الداخلية أو الشريك أو الإدارة.
- اعتماد Warm Ivory هادئ للخلفيات، مع درجات سطح وحدود ونص دافئ متناسقة، وإبقاء الأخضر للروابط المهمة والأزرار.
- اعتماد خط Thmanyah Sans المحلي للعربية لأنه الأنسب للهوية السعودية الحالية، وInter للإنجليزية، مع أوزان قليلة ومنضبطة.
- تحسين أحجام العناوين والنصوص والأزرار والمسافات بشكل مرن بين 375 و768 و1440 بكسل، مع عناية خاصة بأول شاشة والأقسام والبطاقات والتذييل.
- إزالة القيم اللونية الصلبة من عناصر الرئيسية التي تحتاج التوحيد واستبدالها بقيم النطاق الخاصة بالرئيسية.

## حدود صارمة
- التعديل في صفحة `/` وملف تنسيق مخصص لها فقط، مع تغييرات محدودة في مكونات لا تُعرض إلا فيها عند الضرورة.
- لا تغيير للمحتوى أو الصور أو الشعار أو المسارات أو منطق الحجز.
- لا تغيير لأي صفحة Partner أو Admin أو Dashboard أو للبيانات والخدمات الخلفية.

## التحقق
- فحص بصري للرئيسية على 375 و768 و1440 بكسل، بالعربية والإنجليزية.
- التحقق من عدم وجود قص أو تداخل ومن وضوح التباين وسهولة لمس الأزرار.
- تشغيل فحص الأنواع والبناء، ثم التأكد أن التغييرات محصورة في الرئيسية.
