# Tekillah: Your Event, Our Expertise

Subject: Build "Tekillah (تِكِلّة)" - A Luxury Event Management & Smart Booking Platform

Project Vision: > Create a high-end, professional Saudi-based platform named "Tekillah (تِكِلّة)". The name signifies "Trust, Reliance, and Comfort". The platform is an all-in-one smart system for planning and booking events (weddings, ceremonies) from start to finish.

Brand Identity & UI Style:

Primary Colors: Deep Olive Green (#556B2F), Luxury Off-white (#F5F5F0), and Soft Beige (#E8DCCB).

Vibe: Minimalist, Luxurious, Calming, and Trustworthy.

Elements: Large white spaces, warm high-quality imagery, soft Arabic typography (like 'Tajawal' or 'IBM Plex Sans Arabic'), and smooth animations.

Task 1: The Landing Page (Hero Section)

A sophisticated hero section with the headline: "تِكِلّة... خلّي ليلتك علينا" (Tekillah... leave your night to us).

A clear CTA button: "ابدأ تخطيط ليلتك" (Start Planning your night).

Features section highlighting: Smart Planning, Direct Booking, Budget Management, and Real-time Coordination.

Task 2: The Smart Planning Wizard (Phase 1 UI) Create a multi-step interactive wizard for users to start planning:

Event Details: City, Date, Guests (Men/Women counts), Event Type.

Service Selection: Grid of luxury cards (Hall, Catering, Photography, DJ, Decor, Cars).

Budget Mode: Two options: "Ready Packages" or "Smart Budget Allocation" (where the user enters a number and the system suggests a split).

Task 3: Modern Dashboard Preview

Design a "User Dashboard" that shows a progress timeline (e.g., "3 months to go - Confirm Catering").

A "Live Event Mode" toggle that shows the status of vendors on the event day.

Technical Requirement:

Responsive design (Mobile first for the Saudi market).

Support for RTL (Arabic) as primary, with LTR (English) as secondary.

Use Framer Motion for elegant transitions.
